# 🤖 Dexwin Assistant

[![Python](https://img.shields.io/badge/Python-3.9%2B-blue.svg?logo=python&logoColor=white)](https://www.python.org/)
[![Streamlit](https://img.shields.io/badge/Streamlit-Framework-red.svg?logo=streamlit&logoColor=white)](https://streamlit.io/)
![License](https://img.shields.io/badge/License-MIT-green.svg)


An intelligent, modern **Streamlit-powered AI chatbot** designed to serve as a **customer service assistant for Dexwin Tech Ltd**, a digital product development agency based in Ghana.

The assistant provides accurate, friendly, and professional responses about Dexwin’s services, projects, partnerships, and delivery models, powered by **Anthropic Claude (Haiku)**.

---

## 🚀 Features

- ✨ Ultra-modern Streamlit UI with custom CSS
- 💬 Real-time conversational chat interface
- 🤖 Powered by Anthropic Claude (Haiku model)
- 🎨 Dark / Light mode toggle
- 🧠 Category-based filtering (Services, Projects, Partners, etc.)
- 📥 Export chat conversations
- 🔐 Secure API key handling via Streamlit secrets
- 🌍 Business-aware system prompt tailored to Dexwin Tech Ltd
